## 1. 准备密钥与模型 ID

在 [AiLink 控制台](https://ai.ailink1.com/keys)创建并复制 API Key，确认对应订阅有效或余额充足。

### 获取自己订阅的模型 ID

1. 打开[模型广场](https://docs.ailink1.com/models)，选择 **订阅**。
2. 选择自己已开通、且与 API Key 对应的 **分组**，不要停留在 **全部分组**。不确定时，到控制台的 **我的订阅** 中确认。
3. 选择 **模型厂商**；出现 **账号池** 时，再选择准备使用的账号池。一卡通订阅也按此顺序筛选。
4. 点击模型 ID 右侧的 **复制图标**，将完整内容粘贴到 ZCode 的 **模型 ID**，保留大小写和版本后缀。

**可用模型以自己的分组和账号池为准，截图中的模型仅作配置示例。** 余额用户选择 **余额** 和 API Key 对应的分组后，同样复制模型 ID。

## 2. 安装并打开模型设置

从 [ZCode 官方下载页](https://zcode.z.ai/cn)选择适合自己系统的安装包，安装后启动应用。

在 **新建任务** 页面，点击输入框右下角的 **管理模型**，进入 **模型设置**。

::: details 查看“管理模型”的位置

![在 ZCode 新建任务页面的输入框右下角打开管理模型](/uploads/2026/11/8c2ed0a7-c974-4b95-bded-e838336a8dfc.png?v=ailink1)

:::

## 3. 添加 AiLink 供应商

在 **模型设置 → 自定义供应商** 中点击 **＋ 添加供应商**，按下表填写：

| 配置项 | 填写内容 |
| --- | --- |
| 名称 | `AiLink` |
| Base URL | `https://ai.ailink1.com` |
| API Key | 自己的 AiLink Key |
| API 格式 | **Responses (/responses)** |

**Base URL 可直接复制：**

```text
https://ai.ailink1.com
```

此处填写站点地址，无需追加 `/v1` 或 `/responses`。

![在 ZCode 中添加 AiLink 供应商，填写站点地址和 API Key，并选择 Responses API 格式](/uploads/2026/11/65fdaa75-78cd-47d0-a00d-2a94c8b396f4.png?v=ailink1)

填写连接信息后，继续添加模型。**至少保存一个模型，才能提交供应商。**

## 4. 添加模型并保存供应商

在 **模型列表** 中点击 **＋ 添加模型**；修改已有模型时，点击该模型右侧的 **铅笔图标**。

按所选模型填写以下参数：

- **模型 ID**：从[模型广场](https://docs.ailink1.com/models)按自己的分组和账号池复制，确保完整一致。
- **上下文窗口**：填写模型支持的上下文容量，单位为 token。
- **最大输出 Token**：填写模型支持的单次输出上限，与上下文窗口分别设置。
- **输入类型**：保留 **文本**；仅在模型支持时勾选 **图片**、**视频** 或 **PDF**。
- **输出类型**：本教程的文本对话模型保留 **文本**。

![ZCode 模型配置中的模型 ID、上下文窗口、最大输出 Token 和输入输出类型](/uploads/2026/11/9022ac7b-902d-4d7e-b519-2571a8f861f0.png?v=ailink1)

*图中的 270,000 上下文和 128,000 最大输出仅作填写示例，请按所选模型实际支持的容量设置。*

1. 填写完成后，点击模型窗口右下角的 **保存**。
2. 需要使用多个模型时，继续点击 **＋ 添加模型**，分别填写并保存。
3. 返回供应商页面，确认模型已出现在列表中，再点击右下角的 **添加供应商**。

同一供应商下的模型共用 Base URL、API Key 和 API 格式，请确认添加的模型都在该密钥的可用范围内，并支持所选协议。

## 5. 选择模型并开始对话

1. 点击左上角 **返回工作区**，进入 **新建任务**。
2. 点击输入框右下角的模型选择器。
3. 展开 **AiLink**，选择刚添加的模型。

![在 ZCode 模型选择器中展开 AiLink，并选择已添加的模型](/uploads/2026/11/8529f0bb-b0ca-46d9-bd42-95ef45ec75b8.png?v=ailink1)

发送以下测试消息：

```text
你好，请只回复：连接成功。
```

收到正常回复，且没有鉴权、模型或参数错误，即表示接入完成。

![ZCode 使用 AiLink 自定义模型收到正常对话回复](/uploads/2026/11/e8f2473b-fafb-472e-9af0-099a2e7709bb.png?v=ailink1)

*图中以发送“hi”为例。右侧的思考强度仅选择模型支持的档位；更换模型或调整参数后，建议新建任务再测试。*

::: details 验证项目文件读取

需要处理项目文件时，先点击输入框上方的 **选择项目**，选择一个本地项目，再发送：

```text
请列出当前项目根目录的文件，只读取，不修改任何文件。
```

根据任务需要确认读取权限，并检查返回的文件列表是否与项目一致。

:::

## 常见问题

::: details 提示 401、无效密钥或鉴权失败

重新复制完整的 AiLink Key，检查是否有多余空格、密钥是否停用，以及对应订阅或余额是否可用。确认密钥填写在 **AiLink 自定义供应商** 中。

:::

::: details 提示模型不存在、不可用或无权限

在[模型广场](https://docs.ailink1.com/models)选择自己的分组、厂商和账号池，重新复制完整模型 ID。确认 API Key 对应分组包含该模型，并在 **模型列表** 中编辑、保存。

:::

::: details 无法添加供应商，或回到任务页找不到模型

先在供应商的 **模型列表** 中添加至少一个模型，并在模型窗口点击 **保存**；再回到供应商页面点击 **添加供应商**。

回到任务页后，打开模型选择器并展开 **AiLink**。如果列表未更新，重新打开选择器或新建任务查看。

:::

::: details 提示接口不存在、404 或协议不支持

核对 Base URL 为 `https://ai.ailink1.com`，API 格式为 **Responses (/responses)**，不要在地址后重复追加接口路径。确认所选模型支持 Responses 接入方式。

:::

::: details 提示上下文、最大输出或思考参数错误

进入该模型的编辑页面，核对 **上下文窗口** 和 **最大输出 Token** 是否超过模型实际限制。图中的数值不适用于所有模型。

若错误涉及思考参数，在输入框右侧选择模型支持的思考档位，再新建任务，用纯文本消息测试。

:::

::: details 能对话，但无法识别图片或读取项目文件

- **图片识别**：确认模型支持图片输入，并在模型配置的 **输入类型** 中勾选 **图片**。
- **文件读取**：确认已选择正确的项目，模型支持工具调用，并允许任务所需的读取操作。

:::

需要帮助时，请使用页面开头的微信二维码，提供系统版本、ZCode 版本、模型 ID 和错误截图，并遮住完整 API Key。
