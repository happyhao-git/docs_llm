## 1. 准备密钥与模型 ID

在 [AiLink 控制台](https://ai.ailink1.com/keys)创建并复制 API Key，确认对应订阅有效或余额充足。

### 获取自己订阅的模型 ID

1. 打开[模型广场](https://docs.ailink1.com/models)，选择 **订阅**。
2. 选择自己已开通、且与 API Key 对应的 **分组**，不要停留在 **全部分组**。不确定时，到控制台的 **我的订阅** 中确认。
3. 选择 **模型厂商**；出现 **账号池** 时，再选择准备使用的账号池。一卡通订阅也按此顺序筛选。
4. 点击模型 ID 右侧的 **复制图标**，将完整内容粘贴到 Qoder 的 **Model ID**，保留大小写和版本后缀。

**可用模型以自己的分组和账号池为准，截图中的模型仅作配置示例。** 余额用户选择 **余额** 和 API Key 对应的分组后，同样复制模型 ID。

## 2. 安装并打开模型设置

从 [Qoder 官方下载页](https://qoder.com/download)选择适合自己系统的桌面版本，安装后启动并完成登录。

1. 点击左下角的 **齿轮图标 → 设置**。
2. 在设置侧栏中选择 **模型**。
3. 点击右上角 **＋ 添加模型**。

::: details 查看设置入口

![点击 Qoder 左下角齿轮图标，再选择设置](/uploads/2026/11/20596c41-9f02-48da-9bf9-aefdbd6983f6.png)

:::

## 3. 填写 AiLink 连接信息

在 **添加模型** 窗口中，按下表填写：

| 配置项 | 填写内容 |
| --- | --- |
| 供应商 | **OpenAI Compatible** |
| API 类型 | **Responses API** |
| 接口地址（Base URL） | `https://ai.ailink1.com/v1` |
| API Key | 自己的 AiLink Key |
| Model ID | 从[模型广场](https://docs.ailink1.com/models)按自己的分组和账号池复制的完整模型 ID |

**接口地址可直接复制：**

```text
https://ai.ailink1.com/v1
```

这里只填写以 `/v1` 结尾的基础地址，无需追加 `/responses` 或 `/chat/completions`。

需要添加多个模型时，点击 **＋ 添加 Model ID**，每行填写一个模型 ID。图中以 `gpt-6.1-sol` 和 `gpt-6-astra` 为例；填写完成后点击 **下一步**。

![在 Qoder 模型设置中添加 OpenAI Compatible 供应商，选择 Responses API 并填写 AiLink 地址、密钥和模型 ID](/uploads/2026/11/16aaf4ab-1cd8-45e3-a29a-9d0f4fd8cd2a.png)

*同一次添加的模型共用接口地址和 API Key，请确认这些模型都在该密钥的可用范围内。*

## 4. 配置模型能力并校验

在 **配置模型能力** 窗口中，逐个展开模型并核对以下设置：

- **显示名称**：用于在列表中识别模型，建议与 Model ID 一致。
- **Model ID**：保持与模型广场复制的内容一致。
- **支持的上下文窗口 / 默认上下文窗口**：按模型实际支持的容量选择，默认值应在已选范围内。
- **视觉**：仅在模型支持图片输入时开启。
- **思考模式 / 思考强度**：仅选择模型支持的能力和档位；不确定时先保留默认设置。

![Qoder 中 gpt-6.1-sol 的显示名称、模型 ID、上下文窗口和能力设置](/uploads/2026/11/316e0601-ac05-4edd-ae50-add0c9e21959.png)

*图中的 400K 上下文及思考档位仅作示例，请按所选模型的实际能力设置。*

::: details 查看第二个模型的配置示例

添加多个模型时，需要分别检查每个模型的能力设置。

![Qoder 中 gpt-6-astra 的模型能力配置示例](/uploads/2026/11/7b5e553a-b956-4c84-bde7-dbf3cb49a4ac.png)

:::

核对完成后，点击右下角 **校验并添加模型**。如果出现错误，按提示检查接口地址、密钥、模型 ID 和能力参数，再重新校验。

## 5. 选择模型并开始对话

1. 点击 **返回应用**，进入 **新的任务**。
2. 点击输入框右下角的 **模型名称**。
3. 切换到 **自定义**，选择刚添加的模型。

![在 Qoder 输入框右下角打开模型选择器，切换到自定义并选择已添加的模型](/uploads/2026/11/774235ba-eecc-40be-9519-a82d9e97e65a.png)

发送以下测试消息：

```text
你好，请只回复：连接成功。
```

收到正常回复，且没有鉴权、模型或参数错误，即表示接入完成。

![Qoder 使用自定义模型收到正常对话回复](/uploads/2026/11/b6ea9835-6e69-4eab-8cd1-054978f864fe.png)

*图中以发送“hi”为例。更换模型或调整参数后，建议新建任务再测试。*

::: details 验证项目文件读取

需要处理项目文件时，先在输入框下方选择 **工作区**，打开一个本地项目文件夹，再发送：

```text
请列出当前项目根目录的文件，只读取，不修改任何文件。
```

根据任务需要确认读取权限，并检查返回的文件列表是否与项目一致。

:::

## 常见问题

::: details 校验失败，或提示 401、无效密钥

重新复制完整的 AiLink Key，检查是否有多余空格、密钥是否停用，以及对应订阅或余额是否可用。确认接口地址为 `https://ai.ailink1.com/v1`。

:::

::: details 提示模型不存在、不可用或无权限

在[模型广场](https://docs.ailink1.com/models)选择自己的分组、厂商和账号池，重新复制完整模型 ID 到 **Model ID**。确认 API Key 对应分组包含该模型；只修改显示名称不会改变实际调用的模型。

:::

::: details 添加成功，但对话中找不到模型

回到输入框右下角的模型选择器，切换到 **自定义**。如果仍未出现，进入 **设置 → 模型** 确认已完成 **校验并添加模型**，再新建任务查看。

:::

::: details 发送消息时报接口、上下文或思考参数错误

先核对供应商为 **OpenAI Compatible**、API 类型为 **Responses API**，接口地址以 `/v1` 结尾。

再检查上下文窗口和思考档位是否受所选模型支持。先恢复默认思考设置，用纯文本消息测试；上下文超限时，调低窗口至模型支持的范围，或新建任务。

:::

::: details 能对话，但无法识别图片或读取项目文件

- **图片识别**：确认模型支持图片输入，并在模型能力中开启 **视觉**。
- **文件读取**：确认已选择正确的工作区，模型支持工具调用，并允许任务所需的读取操作。

:::

需要帮助时，请使用页面开头的微信二维码，提供系统版本、Qoder 版本、模型 ID 和错误截图，并遮住完整 API Key。
