## 1. 准备 AiLink 密钥

准备好以下两项，再开始配置：

- **API Key**：在 [AiLink 控制台](https://ai.ailink1.com/keys)创建并复制密钥，确认对应订阅有效或余额充足。
- **模型 ID**：必须从[模型广场](https://docs.ailink1.com/models)按自己的订阅分组和账号池获取，步骤如下。

### 获取自己订阅的模型 ID

1. 打开 [AiLink 模型广场](https://docs.ailink1.com/models)，选择 **订阅**。
2. 在顶部的 **分组** 下拉框中，选择自己已开通、且与 API Key 对应的订阅分组；不要停留在 **全部分组**。不确定订阅名称时，先到 AiLink 控制台的 **我的订阅** 中确认。
3. 选择 **模型厂商**；出现 **账号池** 选项时，再选择准备使用的账号池。一卡通订阅也按这个顺序筛选。
4. 在筛选后的列表中找到目标模型，点击模型 ID 右侧的 **复制图标**。
5. 返回本教程的模型配置页面，将复制的完整内容粘贴到 **模型 ID**，保留原有大小写和版本后缀。

**以自己订阅分组和账号池下的列表为准，截图中的模型仅作示例。**

余额用户将付费方式切换为 **余额**，选择 API Key 对应的分组后，同样复制模型 ID。

::: details 首次使用：开通订阅与创建密钥

1. 登录 [AiLink 控制台](https://ai.ailink1.com)，首次使用先注册账号。
2. 开通所需订阅或充值余额；如有兑换码，在 **兑换** 页面完成兑换，并在 **我的订阅** 中确认订阅状态。
3. 打开 **API 密钥**，点击 **创建密钥**，填写便于识别的名称，并选择包含目标模型的分组。
4. 保存后，点击密钥旁的复制按钮，复制完整 API Key。

![在 AiLink 密钥列表中复制密钥](/uploads/2026/11/harness-linkapi-key-2b5fd1624f.webp?v=ailink1)

*图中分组为示例，请选择自己已开通、且包含目标模型的分组。*

:::

## 2. 安装桌面端

打开 [TRAE 官网](https://www.trae.cn/)，下载与你的操作系统匹配的桌面版本。安装后启动应用，并按提示完成登录。

## 3. 添加 AiLink 自定义模型

### 打开模型设置

点击 TRAE 窗口右上角的 **设置** 图标。

![TRAE 窗口右上角的设置入口](/uploads/2026/11/trae-settings-6525b8c977.webp?v=ailink1)

在设置左侧选择 **模型**，再点击 **＋添加模型**。

![在 TRAE 设置中选择模型并点击添加模型](/uploads/2026/11/trae-model-settings-829128128a.webp?v=ailink1)

在弹出的窗口中选择 **自定义模型**。

![TRAE 添加模型窗口中的自定义模型入口](/uploads/2026/11/trae-custom-model-a4195bad65.webp?v=ailink1)

### 填写连接信息

以下以截图中的 `gpt-6.1-sol` 为例，按下表填写：

| 配置项 | 填写内容 |
| --- | --- |
| API 格式 | **OpenAI Responses API 格式** |
| 自定义请求地址 | `https://ai.ailink1.com/v1` |
| 完整 URL | **关闭** |
| 模型 ID | 从[模型广场](https://docs.ailink1.com/models)按自己的订阅分组和账号池复制，所选模型需支持该接口 |
| 模型展示名称 | 可填写与模型 ID 相同的名称；留空时默认显示模型 ID |
| API 密钥 | AiLink Key |

**自定义请求地址：**

```text
https://ai.ailink1.com/v1
```

保持 **完整 URL** 关闭，地址末尾不要再加 `/`。TRAE 会自动补充 `/responses`，这里无需手动追加。

![TRAE 自定义模型的 API 格式、请求地址、模型 ID 与密钥配置](/uploads/2026/11/trae-connection-7f4a5849a1.webp?v=ailink1)

*模型 ID 须与密钥对应分组中的 ID 完全一致。模型展示名称只用于列表显示，不会改变实际调用的模型。*

## 4. 核对模型参数

展开 **高级配置**，按所选模型的实际能力填写。首次接入时可先保留默认设置，完成对话验证后再调整。

| 配置项 | 设置方式 |
| --- | --- |
| 模型系列 | 选择与模型匹配的系列；截图使用 **GPT-6系列**，没有对应选项时保留默认配置 |
| 上下文窗口：输入 | 填写所选模型支持的输入上限，单位为 token |
| 上下文窗口：输出 | 不超过所选模型支持的单次输出上限，单位为 token |
| 工具调用轮数 | 按任务需要设置；首次使用可保留默认值 |
| 支持图片输入 | 仅为支持图片的模型选择 **支持** |
| 思考模式：参数名 | 本教程的 Responses 接口使用 `reasoning.effort` |
| 思考模式：可选值列表 | 仅添加所选模型支持的推理档位；不确定时保留默认设置 |

![TRAE 高级配置中的模型系列、输入输出上限、图片输入与思考模式](/uploads/2026/11/trae-model-options-d10a89f836.webp?v=ailink1)

*图中输入 `262144`、输出 `131072`、工具调用轮数 `500`，以及 `high`、`xhigh`、`max` 档位均为配置示例，请按所选模型填写。*

完成后点击 **添加模型**；编辑已有模型时点击 **保存模型**。

需要添加其他模型时，重复 **模型 → 添加模型 → 自定义模型** 的操作，分别填写模型 ID，并重新核对 API 格式和高级参数。

## 5. 验证连接

1. 返回主界面，打开 **与 AI 对话**，新建对话。
2. 点击输入框底部的模型名称，选择刚添加的自定义模型。
3. 发送以下测试消息：

```text
你好，请只回复：连接成功。
```

收到正常回复，且没有鉴权、模型或参数错误，即表示接入完成。

![在 TRAE 对话中选择 gpt-6.1-sol 并收到正常回复](/uploads/2026/11/trae-chat-e1ef670094.webp?v=ailink1)

*更换模型或调整参数后，建议新建对话再测试。需要读写项目文件时，先打开对应的本地项目文件夹。*

## 常见问题

::: details 提示 401、无效密钥或鉴权失败

重新复制完整 AiLink Key，检查是否漏复制、粘贴了多余空格，或密钥已被停用。确认密钥填在本教程创建的 **自定义模型** 中。

:::

::: details 提示 404、接口不存在或请求地址错误

核对 **API 格式** 为 **OpenAI Responses API 格式**、**完整 URL** 为关闭状态，并将请求地址填写为 `https://ai.ailink1.com/v1`。检查是否多加了末尾斜杠，或重复填写了 `/responses`。

:::

::: details 提示模型不存在、不可用或无权限

在[模型广场](https://docs.ailink1.com/models)选择自己的订阅分组和账号池，重新复制模型 ID，确认密钥所选分组包含该模型、模型支持所选 API 格式。订阅用户检查订阅和额度；余额用户检查账户余额。

:::

::: details 保存成功，但发送消息时报参数错误

检查输入输出上限和推理档位是否受模型支持。使用本教程的 Responses 接口时，思考模式参数名为 `reasoning.effort`。先恢复默认高级配置，用纯文本消息测试，再逐项调整。

:::

::: details 普通对话正常，但无法发送图片

先确认模型本身支持图片输入，再打开该模型的 **高级配置**，将 **支持图片输入** 设为 **支持**。保存后新建对话测试。

:::

::: details 添加的模型没有出现在当前对话中

先到 **设置 → 模型** 确认模型已添加并保存，再新建对话，从输入框底部的模型选择器中查找。列表按 **模型展示名称** 显示，未填写时显示模型 ID。

:::

需要技术支持时，请使用页面开头的微信二维码，并提供系统版本、TRAE 版本、模型 ID 和错误截图。
