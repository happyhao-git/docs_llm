## 1. 准备 LinkAPI 密钥

准备好以下两项，再开始配置：

- **API Key**：在 [LinkAPI 控制台](https://ai.ailink1.com/keys)创建并复制密钥，确认对应订阅有效或余额充足。
- **模型 ID**：必须从[模型广场](https://docs.ailink1.com/models)按自己的订阅分组和账号池获取，步骤如下。

### 获取自己订阅的模型 ID

1. 打开 [LinkAPI 模型广场](https://docs.ailink1.com/models)，选择 **订阅**。
2. 在顶部的 **分组** 下拉框中，选择自己已开通、且与 API Key 对应的订阅分组；不要停留在 **全部分组**。不确定订阅名称时，先到 LinkAPI 控制台的 **我的订阅** 中确认。
3. 选择 **模型厂商**；出现 **账号池** 选项时，再选择准备使用的账号池。一卡通订阅也按这个顺序筛选。
4. 在筛选后的列表中找到目标模型，点击模型 ID 右侧的 **复制图标**。
5. 返回本教程的模型配置页面，将复制的完整内容粘贴到 **模型 ID**，保留原有大小写和版本后缀。

**以自己订阅分组和账号池下的列表为准，截图中的模型仅作示例。**

余额用户将付费方式切换为 **余额**，选择 API Key 对应的分组后，同样复制模型 ID。

::: details 首次使用：开通订阅与创建密钥

1. 登录 [LinkAPI 控制台](https://ai.ailink1.com)，首次使用先注册账号。
2. 开通所需订阅或充值余额；如有兑换码，在 **兑换** 页面完成兑换，并在 **我的订阅** 中确认订阅状态。
3. 打开 **API 密钥**，点击 **创建密钥**，填写便于识别的名称，并选择包含目标模型的分组。
4. 保存后，点击密钥旁的复制按钮，复制完整 API Key。

![在 LinkAPI API 密钥列表中复制密钥](/uploads/2026/11/harness-linkapi-key-2b5fd1624f.webp)

*图中分组为示例，请选择自己已开通、且包含目标模型的分组。*

:::

## 3. 添加 LinkAPI 供应商

### 打开模型设置

点击左下角 **更多 → 设置**，进入 **模型** 页面，再点击 **＋添加模型供应商**。选择 **自定义模型 API**。

::: details 查看“更多 → 设置”的位置

![DeepSeek Harness 左下角的更多菜单与设置入口](/uploads/2026/11/harness-settings-dae9dfb8be.webp)

:::

![在模型设置中添加模型供应商](/uploads/2026/11/harness-add-provider-748cb260f9.webp)

### 填写连接信息

将 LinkAPI 添加为自定义供应商，按下表填写。LinkAPI 密钥应填写在这个供应商中。

| 配置项 | 填写内容 |
| --- | --- |
| 供应商 ID | `linkapi` |
| 显示名称 | `LinkAPI` |
| API 地址 | `https://ai.ailink1.com/v1` |
| API 协议 | **OpenAI Response** |
| API 密钥 | LinkAPI API Key |

**API 地址：**

```text
https://ai.ailink1.com/v1
```

这里只填写以 `/v1` 结尾的基础地址，无需追加 `/response`。


![配置页面](/uploads/2026/11/a25ab271-0138-4eef-b886-b5f4f752a19c.png)


*已保存的密钥会显示为占位提示，不会再次明文展示。*

## 4. 添加模型并设置参数

### 获取可用模型

在供应商的 **模型目录** 中点击 **获取可用模型**，搜索并勾选需要的模型，再点击 **添加所选**。

在[模型广场](https://docs.ailink1.com/models)按自己的订阅分组、模型厂商和账号池核对可用范围。如果获取失败或列表为空，从筛选后的列表复制模型 ID，再手动添加。**模型 ID 必须完整一致**；显示名称可自行填写。

### 核对模型能力

展开模型右侧的 **模型选项**，按所选模型的实际能力设置：

- **上下文窗口**：填写该模型支持的上下文上限，单位为 token。
- **最大输出 token 数**：不超过该模型支持的单次输出上限。
- **输入类型**：保留 **文本**；只有支持图片输入的模型才勾选 **图片**。
- **推理等级**：仅为支持推理档位的模型开启，并添加接口支持的档位。

![模型选项中的上下文窗口、最大输出、图片输入与推理等级](/uploads/2026/11/harness-model-options-b9d6be4e04.webp)

*图中容量数值与推理档位仅作界面示例，请按所选模型填写。*

::: tip 推理等级怎么填

每一行由 **档位** 和 **API 参数值** 组成。如果模型支持 `low`、`medium`、`high`，两列可分别填写相同值。不确定时先保留默认设置；`xhigh`、`max` 等档位仅在接口明确支持时添加。

:::

完成后点击 **创建** 或 **保存**。需要使用多个模型时，在同一个 LinkAPI 供应商中继续添加即可。

## 5. 验证连接

1. 关闭设置，点击 **新会话**。
2. 选择一个工作区；尚未添加时，先选择本地文件夹作为工作区。
3. 点击输入框右下角的模型名称，选择刚添加的 **LinkAPI** 下的模型。
4. 发送以下测试消息：

```text
你好，请只回复：连接成功。
```

收到正常回复，且没有鉴权、模型或参数错误，即表示接入完成。

![选择已配置模型后，在 DeepSeek Harness 中收到正常回复](/uploads/2026/11/harness-chat-16480e42db.webp)

*模型在输入框右下角切换。更换模型或调整参数后，建议新建会话再测试。*

## 6. 添加开源联网搜索（可选）

如果不想使用 DSH 自带的付费联网功能，可以安装开源项目 [free-search-mcp](https://github.com/ymylive/free-search-mcp)，为 DeepSeek Harness（DSH）添加联网搜索能力。

先完成前面的模型接入与连接验证，再按以下步骤配置。

### 安装与配置

1. **开启代理**，确认网络连接正常，可以访问 GitHub 项目页面。
2. 在 DSH 中**新建会话**，将模型切换为 `gpt-6-astra`。
3. 复制下方完整内容并发送给 DSH，让它根据当前系统环境完成安装和接入。

**发送内容：**

```text
请帮我安装并配置以下开源 MCP 项目，为 DeepSeek Harness（DSH）添加联网搜索功能：

https://github.com/ymylive/free-search-mcp

具体要求：
1. 先阅读项目说明，根据我当前的系统环境和 DSH 配置完成安装。
2. 我已开启代理；如安装或运行需要代理，请优先使用现有代理配置。
3. 将该 MCP 接入 DSH，并通过一次实际搜索验证是否可以正常使用。
4. 联网搜索请使用这个 MCP，不要调用 DSH 自带的付费联网功能，也不要在该 MCP 不可用时自动回退到付费功能。
5. 完成后，请告诉我如何使用，以及后续启动 DSH 时是否需要额外操作。

如果缺少必要信息，或遇到需要付费的依赖或服务，请先说明，再继续操作。
```

### 验证与后续使用

- **检查实际搜索结果**：安装完成后，核对搜索结果与工具调用记录，确认联网搜索由 `free-search-mcp` 完成。
- **确认启动方式**：请 DSH 说明后续打开应用时，MCP 是否自动启动，以及是否需要保持代理或额外进程运行。
- **明确工具范围**：后续需要联网时，可在任务中指定“仅使用 `free-search-mcp`”；如果工具不可用，先排查原因，不自动切换到付费联网功能。

::: info 费用说明

本节替换的是联网搜索工具，LinkAPI 模型调用仍按所选分组计费。涉及额外付费依赖或服务时，先确认再启用。

:::


## 常见问题

::: details 获取不到可用模型，怎么办？

先核对 API 地址为 `https://ai.ailink1.com/v1`，并确认密钥完整有效。如果仍然无法获取，手动填写对应分组中的模型 ID，再保存并测试对话。模型列表获取失败不一定代表对话接口不可用。

:::

::: details 提示 401、无效密钥或 MISSING_CREDENTIAL

重新复制 LinkAPI API Key，检查是否漏复制、粘贴了多余空格，或密钥已被停用。确认密钥填在 **LinkAPI 自定义供应商** 中；首次配置不能将密钥留空。

:::

::: details 提示 UNKNOWN_MODEL、模型不存在或无权限

在[模型广场](https://docs.ailink1.com/models)选择自己的订阅分组和账号池，重新复制模型 ID，确认密钥所选分组包含该模型。订阅用户同时检查订阅是否有效、额度是否可用；余额用户检查账户余额。

:::

::: details 保存成功，但发送消息时报参数错误

先确认协议与第 3 节的配置一致，再检查最大输出是否超过模型上限，以及推理档位是否受支持。取消自行添加的可选参数，用纯文本消息重新测试。仍失败时，保留具体错误提示并联系技术支持。

:::

::: details 输入框无法发送消息

确认已选择工作区和模型。尚未添加工作区时，先选择一个本地文件夹，再新建会话。

:::

::: details 无法发送图片，或带图片的消息报错

先确认模型支持图片输入，再到 **模型选项 → 输入类型** 勾选 **图片**。如果模型本身不支持图片，勾选后也无法使用；请切换到支持图片的模型，并新建会话测试。

:::

::: details MCP 安装或联网搜索失败，怎么办？

先确认代理可用，并检查 DSH 给出的安装日志、依赖和启动提示。请它核对 MCP 是否已接入、相关进程是否运行，再重新执行一次搜索验证。排查期间继续保留“不得自动回退到付费联网功能”的要求；涉及新增付费服务时，先确认再启用。

:::

需要技术支持时，请使用页面开头的微信二维码，并提供系统版本、DeepSeek Harness 版本、模型 ID 和错误截图。截图前请遮住完整 API Key。

更多模型设置可参阅 [DeepSeek Harness 官方配置说明](https://deepseek-harness.github.io/deepseek-harness/guide/providers)。
