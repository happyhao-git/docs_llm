# 文档维护与本次优化

客户内容以数据库中的草稿及发布版本为准，`content/*.md` 是本次经整理的六篇教程快照，不会在应用启动时自动覆盖后台修改。

## 后续维护

优先在管理后台编辑、预览、保存，再查看发布摘要。无可见变更时显示“已是最新”，重复发布接口也不会创建新版本。仅更新一篇文章时，其他文章保留原更新时间。

批量维护时先导出当前草稿：

```bash
node scripts/content-sync.mjs export /安全位置/本次导出
```

在导出目录修改 Markdown 和 manifest 后，先试运行再应用：

```bash
node scripts/content-sync.mjs import /安全位置/本次导出/manifest.json
node scripts/content-sync.mjs import /安全位置/本次导出/manifest.json --apply
```

导出文件可能包含尚未公开的草稿，应保存在访问受限的目录。同步工具读取项目现有数据库环境变量；不要把测试配置和生产配置混用。`--apply` 只更新草稿，不执行发布。

导出时记录文章及分组哈希，导入使用事务与发布锁。如果后台内容已被其他人修改，会中止整个导入；请重新导出并合并，而不是手工更换哈希。历史版本、文章 ID、原有 slug 和媒体文件不会被该工具重建或删除。

当前 `content/manifest.json` 是本次优化的单次迁移清单，应用后不可重复覆盖。下一次批量修改须重新导出。

## 内容语法

- `::: support 微信技术支持`：正文开头直接展示微信原图，桌面宽度约 370px，手机端自适应；保留点击放大，不加重复提醒。
- `::: details 标题`：可折叠的补充说明，正文保留完整阅读和复制能力。
- `<!-- anchors: 旧锚点 | 另一个旧锚点 -->`：改标题时保留旧章节链接。不要删掉已有兼容锚点或创建重复 ID。
- 代码块较长时自动折叠，复制按钮始终复制完整代码。
- Markdown 不允许任意 HTML，以上组件由服务端受控渲染和清理。
- 第三方 Agent 教程必须在模型配置前直接展示模型 ID 获取步骤，并链接 `https://docs.ailink1.com/models`：选择订阅、自己的订阅分组、模型厂商和账号池，再复制完整模型 ID。配置表格或手动添加说明也应提供该链接；示例模型不能代替用户实际可用的模型 ID。余额用户选择余额及密钥对应分组。

## 加载与切换性能

- 使用系统中文字体，避免首次阅读下载多个中文字库分片。
- 教程首次打开时并行请求目录和正文；正文使用最多 20 篇的内存缓存。
- 在空闲、指向或聚焦教程链接时预取相邻文章；省流量模式及 2G 网络停用预取。
- 切换教程和返回浏览器标签页时后台检查发布版本。版本改变会淘汰旧缓存，错误及未找到的文章不缓存。
- 滚动使用预先测量的标题位置，正文尺寸变化时重新测量；进度条通过 transform 更新。
- 带内容哈希的构建资源使用长期缓存，HTML 入口始终重新验证。
- 性能更新不改正文、图片、分组、草稿或发布记录。回归测试包含缓存刷新、已下线文章、请求竞态和省流量模式。
